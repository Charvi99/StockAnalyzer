## 4. Key Insights & Recommendations

### What Works

1. **Binary Classification** ✅
   - 76.8% AUC with ensemble
   - 0% catastrophic error at all thresholds
   - CatBoost performs consistently well
   - Stacking ensemble adds +0.1% AUC

2. **CatBoost** ✅
   - Consistently outperforms XGBoost across all classification types
   - Better precision-recall tradeoff
   - More stable training

3. **Confidence Thresholds** ✅
   - Can significantly reduce catastrophic errors
   - Trade precision for coverage (tunable based on risk tolerance)
   - Threshold 0.6-0.7 provides good balance for binary

### What Doesn't Work

1. **Stacking Ensemble for Multi-Class** ❌
   - 3-class: Accuracy drops 60.2% → 49.5%
   - 5-class: Accuracy drops 52.4% → 36.6%
   - Meta-learner collapses to predicting HOLD
   - **Solution**: Use `weighted_average` or CatBoost alone

2. **5-Class Classification** ❌
   - 18.4% catastrophic error (too risky)
   - Poor separation between adjacent classes (SELL↔HOLD↔BUY)
   - Model confusion between SELL and STRONG SELL
   - **Solution**: Stick to binary or 3-class

3. **TCN Model** ⚠️
   - Memory issues in Docker container
   - Requires sequence creation (expensive)
   - Doesn't significantly improve accuracy over tree-based models
   - **Solution**: Use `--skip-tcn` flag

### What to Avoid

- ❌ 5-class classification (18% catastrophic error)
